# Northstar Catalog

A polished e-commerce product catalog built with React, React Router, and Vite.

## Features
- Modular React app structure
- Client-side routing for Home, Catalog, Product Details, About, and Contact pages
- Optimized images and lightweight styling
- Production build verified with Vite

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
This app is ready to deploy to Vercel or Netlify by linking the project folder.
